# 🎙️ Consent-Based Live Voice Chat Demo

This repository contains a **consent-based live voice chat demo** created strictly for **educational and learning purposes**.  
The project demonstrates how **real-time audio communication** works using **Python WebSockets** and **browser microphone permissions**, while fully respecting **user privacy and consent**.

Microphone access is enabled **only after explicit user approval**.  
There is no hidden listening, background recording, or permanent audio storage.

---

## 🚀 Features
- Real-time voice streaming (demo level)
- Explicit browser microphone permission
- Python WebSocket server
- Lightweight and Termux-compatible
- No audio recording or data storage
- Privacy-first and ethical design
